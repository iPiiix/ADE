## 1. Conceptos Fundamentales

* **Expresión algebraica:** Combinación de números (coeficientes) y letras (variables) ligados por operaciones aritméticas.
  - *Ejemplo del PDF:* $\pi r^2$ es la expresión algebraica que calcula el área de un círculo de radio $r$.
* **Monomio:** Término formado por el producto de un coeficiente numérico y variables elevadas a exponentes naturales.
  - *Ejemplo:* $-3x^2 y$ $\implies$ Coeficiente: $-3$, Parte literal: $x^2 y$, Grado: $2 + 1 = 3$.

## 2. Las 3 Identidades Notables Sagradas

En la UMU se exige dominarlas con soltura:

$$\begin{aligned}
\text{1. Cuadrado de una suma:} &\quad (a + b)^2 = a^2 + 2ab + b^2 \\
\text{2. Cuadrado de una resta:} &\quad (a - b)^2 = a^2 - 2ab + b^2 \\
\text{3. Suma por diferencia:} &\quad (a + b)(a - b) = a^2 - b^2
\end{aligned}$$

> ⚠️ **¡Cuidado con el error típico!** $(a + b)^2 \ne a^2 + b^2$. Siempre lleva el doble producto $2ab$.  
> *Ejemplo:* $(x + 5)^2 = x^2 + 2 \cdot x \cdot 5 + 5^2 = x^2 + 10x + 25$.

## 3. Fracciones Algebraicas y Factorización

### 3.1. Factor Común
Consiste en aplicar la propiedad distributiva a la inversa:
$$3x^2 + 6x = 3x(x + 2)$$

### 3.2. Simplificación (Ejemplo Oficial del PDF)
Para simplificar una fracción con polinomios, primero **factorizamos** usando identidades notables o factor común:
$$\frac{x^2 - 9}{x^2 + 6x + 9} = \frac{(x + 3)(x - 3)}{(x + 3)^2} = \mathbf{\frac{x - 3}{x + 3}}$$
*(Nunca taches sumandos; solo factores que estén multiplicando a todo el numerador y denominador)*.
