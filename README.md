## 🗂️ Estructura Sugerida por Asignatura

Para mantener los recursos organizados a lo largo del curso, se recomienda estructurar el contenido de cada materia de la siguiente manera:

```text
Nombre_Asignatura/
├── Apuntes/          # Resúmenes y notas de clase (Markdown o PDF)
├── Prácticas/        # Casos prácticos, ejercicios resueltos y entregas
├── Diapositivas/     # Presentaciones facilitadas por el profesorado
└── Exámenes/         # Modelos de examen y autoevaluaciones
```
